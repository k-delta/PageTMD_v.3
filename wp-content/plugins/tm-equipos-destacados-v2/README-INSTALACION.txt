TM Equipos Destacados v2.1.0

Qué corrige:
- Detecta el post type tmd_equipo, además de equipo, equipos y product.
- Agrega menú visible en WordPress: TM Destacados.
- Agrega el shortcode seguro [tm_equipos_destacados_v2].
- Conserva también [tm_equipos_destacados].
- Permite configurar YouTube, Instagram y Facebook desde el admin.

Instalación recomendada:
1. WordPress > Plugins > Añadir nuevo > Subir plugin.
2. Sube tm-equipos-destacados-v2.zip.
3. Si WordPress pregunta si quieres reemplazar el plugin anterior TM Equipos Destacados, acepta.
4. Activa el plugin.
5. Ve al menú lateral: TM Destacados.
6. Verifica que detecte el post type tmd_equipo.
7. Edita cada equipo que quieras mostrar y marca “Mostrar en Equipos Destacados”.
8. Llena condición, año, energía, capacidad, altura y orden.
9. En el home, reemplaza la sección vieja de Equipos Destacados por:
   [tm_equipos_destacados_v2]

Footer:
- Ve a TM Destacados.
- Pega las URL de YouTube, Instagram y Facebook.
- Si el cambio automático no toma los iconos del footer, pega este shortcode donde vayan las redes:
  [tm_footer_social_links]

Nota:
Si mantienes activo el plugin viejo, usa [tm_equipos_destacados_v2] para evitar conflicto de shortcode.
