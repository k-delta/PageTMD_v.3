# Handoffs

Esta carpeta contiene transferencias de contexto entre sesiones o personas.

Un handoff debe indicar:

- Fecha.
- Objetivo de la sesión.
- Cambios realizados.
- Archivos modificados.
- Validaciones ejecutadas.
- Estado verificado.
- Riesgos.
- Trabajo pendiente enlazado a un ticket o `SPEC`.

Los handoffs son históricos. No deben tratarse como fuente actual sin volver a verificar.
