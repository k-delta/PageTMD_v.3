# WooCommerce y comercio

## Uso activo

WooCommerce se utiliza para:

- Registro.
- Inicio de sesión.
- Recuperación de cuenta.
- Administración básica de usuario.

Ruta principal: `/mi-cuenta/`.

## Funciones pausadas

Mientras no exista autorización comercial, deben permanecer desactivados:

- Tienda.
- Carrito.
- Checkout.
- Pagos.
- Cupones.
- Venta de repuestos.
- Publicación automática de productos.

## Assets

Los recursos de WooCommerce pueden eliminarse de páginas no relacionadas para mejorar rendimiento, pero deben conservarse donde sean necesarios para login, registro, cuenta y validaciones.

## Reactivación futura

No habilitar comercio sin:

1. Fuente real de productos.
2. Reglas de precios.
3. Inventario sincronizado.
4. Pasarela aprobada.
5. Políticas comerciales.
6. Pruebas de compra.
7. Revisión de seguridad.
