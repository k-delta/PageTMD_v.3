# SEO

## Autoridad

Rank Math controla:

- Title.
- Meta description.
- Canonical.
- Robots.
- Open Graph.
- Schema.
- Sitemap.

El código propio no debe duplicar estas etiquetas sin una necesidad comprobada.

## Schema

- Organización: `Organization` o `LocalBusiness`.
- Páginas comerciales: `WebPage`.
- Alquiler y mantenimiento: `Service`.
- Artículos: `BlogPosting`.

No usar schema de artículo en páginas comerciales.

## Sitemap

Debe incluir únicamente contenido indexable aprobado.

No incluir:

- Cuenta.
- Carrito.
- Checkout.
- Redirecciones.
- Utilidades internas.
- CPT históricos.
- Contenido sin valor de búsqueda.

## Cambios SEO

Después de modificar SEO:

1. Purgar caché.
2. Regenerar o invalidar sitemap.
3. Revisar HTML real.
4. Verificar canonical y robots.
5. Revisar JSON-LD.
6. Confirmar HTTP 200 para URLs indexables.
7. Verificar que cada URL aparezca una sola vez.

## Reglas editoriales

- No cambiar hechos del negocio por palabras clave.
- No inventar ubicaciones, servicios o disponibilidad.
- Mantener la prioridad comercial definida para cada sección.
