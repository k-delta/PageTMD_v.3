# Especificaciones

Esta carpeta contiene especificaciones de tareas concretas.

## Convención de nombres

```text
YYYY-MM-DD-nombre-corto.md
```

Ejemplo:

```text
2026-07-29-invoice-detail-endpoint.md
```

## Estados sugeridos

- Borrador.
- Aprobado.
- En desarrollo.
- Terminado.
- Cancelado.

## Reglas

- Un `SPEC` describe qué debe construirse.
- No debe contener reglas permanentes del repositorio.
- Debe incluir alcance, criterios de aceptación y validación.
- Las decisiones posteriores deben registrarse dentro del mismo documento.
- Cuando deja de estar vigente, debe marcarse claramente.

Usar `TEMPLATE.md` como punto de partida.
